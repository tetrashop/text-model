# text-model | دستیار هوشمند مدل‌سازی سه‌بعدی 🚀

**text-model** is an AI-powered Text-to-CAD web application that converts natural language descriptions and technical drawings into downloadable 3D models (STL/OBJ). Built with Next.js, JSCAD, Three.js, and Groq API.

**text-model** یک وب‌اپلیکیشن هوشمند است که توصیف‌های متنی فارسی و نقشه‌های مهندسی را به مدل‌های سه‌بعدی قابل دانلود (STL و OBJ) تبدیل می‌کند. این پروژه با استفاده از Next.js، کتابخانه CSG جی‌اس‌کد (JSCAD) و مدل‌های بینایی و زبانی Groq ساخته شده است.

---

## ✨ ویژگی‌های کلیدی (Features)

- 🧠 **هوش مصنوعی پارامتریک:** تبدیل توصیف متنی به ساختار JSON (شناسنامه فنی) با استفاده از مدل‌های Llama/Qwen در Groq.
- 📸 **پردازش تصویر و OCR:** استخراج ابعاد و متن از نقشه‌های مهندسی با استفاده از مدل بینایی `qwen` در Groq.
- ⚙️ **عملیات بولین (CSG):** پشتیبانی از ترکیب اشکال (Union) و ایجاد سوراخ (Subtract) با استفاده از `@jscad/modeling`.
- 🖥️ **پیش‌نمایش سه‌بعدی درون‌برنامه:** رندر مدل‌ها در مرورگر بدون نیاز به نرم‌افزار جانبی با `@react-three/fiber`.
- ✏️ **ویرایش زنده ابعاد:** تغییر ابعاد (طول، عرض، شعاع) به صورت آنی و مشاهده تغییرات مدل در لحظه.
- 📦 **خروجی چندگانه:** دانلود مدل‌ها در فرمت‌های استاندارد صنعتی **STL** و گرافیکی **OBJ**.

---

## 🛠 پیش‌نیازها (Tech Stack)

- Next.js 14 (App Router)
- React 18 + Tailwind/CSS
- Groq API (مدل‌های زبانی و بینایی)
- JSCAD (موتور ساخت هندسه سه‌بعدی)
- Three.js (موتور رندر سه‌بعدی)

## 🚀 نصب و اجرا در محیط محلی (Local Setup)

این پروژه به راحتی در **Termux** (اندروید) یا هر ترمینال لینوکس/مک/ویندوزی اجرا می‌شود.

**۱. کلون کردن مخزن:**
```bash
git clone https://github.com/tetrashop/text-model.git
cd text-model
```

۲. نصب پکیج‌ها:

```bash
npm install
```

۳. تنظیم کلید API:
یک فایل به نام .env.local در ریشه پروژه بسازید و کلید رایگان Groq خود را در آن قرار دهید (از console.groq.com دریافت کنید):

```bash
echo "GROQ_API_KEY=gsk_..." > .env.local
```

۴. اجرای پروژه:

```bash
npm run dev
```

برنامه روی http://localhost:3000 اجرا می‌شود.

☁️ دیپلوی روی Vercel (Deployment)

1. مخزن را به گیت‌هاب پوش کنید.
2. در Vercel یک پروژه جدید بسازید و مخزن را وارد کنید.
3. در بخش Environment Variables، متغیر GROQ_API_KEY را با کلید خود مقداردهی کنید.
4. دکمه Deploy را بزنید.

📖 نحوه استفاده (How to Use)

1. توصیف متنی: در چت بنویسید: «یک مکعب ۵۰ در ۳۰ در ۲۰ میلی‌متر بساز که یک سوراخ به شعاع ۵ از وسط آن رد شده باشد.»
2. آپلود نقشه: روی دکمه آپلود رسم کلیک کنید و عکس یک نقشه مهندسی را انتخاب کنید. هوش مصنوعی ابعاد را استخراج می‌کند.
3. ویرایش: پس از ساخت مدل (action: ready)، از بخش «ویرایش ابعاد» مقادیر را تغییر دهید.
4. دانلود: مدل را با فرمت STL یا OBJ دانلود کنید.
